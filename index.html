How to use them

  • Yellow "Exam angle" boxes mark the points most likely to be tested, including the sample questions shown on the lecture slides.
  • Code blocks highlight the lines that matter in amber. You will not write code, but you will be asked to name the tool behind a snippet, so notice what each kind of file looks like as you read.
  • Practice sections hide their answers. Answer first, then open. For true / false, practice writing the corrected word, because a plain "not" earns nothing.
  • The exam drill page is the closest thing to the real paper: name the tool from a snippet, true / false with corrections, matching.
  • Need a definition fast? The glossary answers "what is Git Flow / diff time / blast radius…?" in a sentence or two, and marks which wordings come straight from the slides.
  • Short on time? Start with the study-guide map on the WS7 page: every study-guide bullet, the page it lives on, and a one-line answer. Then do the mixed practice.

A reading order that follows one change to production

Exam format in brief

  • Three question types only (midterm review deck): matching concepts, distinguishing code kinds (name the tool from a snippet), and true / false with corrections.
  • Not on the exam: coding or scripting, open-ended "define the term" questions, fill-in-the-blank.
  • Paper, in class, pen preferred, no notes, assigned seats, no devices or smart watches. Cover your answers with the paper provided.
  • Excluded even though on slides: DevOps job postings, semantically rich identifiers, unikernels, reverse proxy, docker command syntax.

Practise all three on the exam drill page. On the workshop pages, items labelled "Self-check" and "Read the code" are there to build understanding; they are not exam formats.

What to double-check against your notes

  • Many slides are images only. The key ones were read (Git Flow, Ansible, feature flags, rings, shift-left, silos, pipelines), but not every slide.
  • Adages 4 ("Invest for survival") and 9 ("Invite privacy and security in") are only listed on the slides, so their explanations come from the source paper.
  • Definitions of blast radius, shift left / right, load balancer, change management and continuous delivery are written from general knowledge, because the slides give only a diagram or a bare term.
